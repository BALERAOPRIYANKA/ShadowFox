## Assignment Overview

This project implements a Hangman word guessing game using Python. The player has to guess the hidden word one letter at a time. The game provides hints, displays visual progress, and allows a limited number of incorrect guesses before the game ends.

## Features

- Random word selection
- Hints for each word
- Visual Hangman progress
- Letter-by-letter guessing
- Win and Lose conditions
- User-friendly interface

## Technologies Used

- Python
- Random Module

## Files Included

- `hangman.py` – Main source code
- `README.md` – Project documentation

## How to Run

1. Open the project folder in VS Code.
2. Open the terminal.
3. Run the following command:

```bash
python hangman.py
```
